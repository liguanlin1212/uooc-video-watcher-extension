# UOOC Video Watcher

面向 `https://www.uooc.net.cn/` 的 Chrome/Edge Manifest V3 扩展，只做视频状态监控与提醒，不对平台页面行为做任何主动干预。

## 功能

- 自动监控匹配的 UOOC 页面，无需每页手动开启。
- 视频暂停超过 1 分钟时，发送一次系统通知并播放扩展提示音。
- 视频播放结束时，发送一次“需要手动切换下一个视频”的提醒。
- 疑似被题目弹窗或遮罩卡住时，发送一次提醒。
- 支持多个视频标签页并行监控。
- 扩展弹窗支持：
  - 全局监控开关
  - 单标签监控开关
  - “我确实要暂停”免提醒按钮
  - 测试提示音

## 加载方式

1. 打开 `Chrome` 或 `Edge` 的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择当前目录 `D:\codex_all\uooc-video-watcher-extension`。

## 使用说明

- 打开 UOOC 视频页后，扩展会自动查找当前页主要的 `video` 元素并开始监控。
- 如果视频暂停超过 60 秒、自然结束、或页面出现疑似阻塞视频的弹窗，扩展会触发通知和提示音。
- 如果你是主动暂停，点击扩展弹窗中的“我确实要暂停”，该标签页会进入免提醒状态；重新播放后会自动恢复提醒。

## 边界

- 不自动答题。
- 不自动切换视频。
- 不拦截、不修改、不绕过平台页面逻辑。
- 不模拟用户操作。

## 已知限制

- 第一版只支持桌面 `Chrome/Edge`。
- 疑似弹题检测依赖页面 DOM 结构和遮罩特征；站点改版后可能需要更新选择器。
